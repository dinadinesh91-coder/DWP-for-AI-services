# Structured Triage Summary

## Summary (one line)
User reports that everything is slow after upgrading to Windows 11 two days ago.

## Impact (who/how many/business urgency)
- Who: One end user on a recently upgraded Windows 11 device (to-verify).
- How many: Single reported user/device so far (to-verify).
- Business urgency: Medium to high because broad device slowness can affect all user activity (to-verify).

## Known facts
- Ticket reference is T-1006.
- The user says everything is slow.
- The device was upgraded to Windows 11 two days ago.

## Missing information to gather
- Whether slowness affects startup, sign-in, apps, browser, file access, or all of them.
- Whether the issue started immediately after the upgrade or later.
- Current CPU, memory, disk, and storage free space at time of issue.
- Whether the device is on battery or docked and whether power mode changed after upgrade.
- Whether there are pending updates, indexing, sync activity, or first-run post-upgrade tasks still running (to-verify).
- Whether specific apps are worse than others.
- Whether any other recently upgraded Windows 11 devices show the same behavior.

## Likely category
Post-upgrade Windows 11 endpoint performance issue.

## First diagnostic step
Confirm whether the slowdown is broad or app-specific by checking current device resource usage during the issue; this quickly distinguishes a general post-upgrade performance problem from a single application bottleneck.

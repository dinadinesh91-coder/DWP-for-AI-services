# Bad Prompt Example

## Raw prompt
Citrix is very slow for SD team.

## Why this is a bad prompt
- It does not state whether the user wants a triage summary, incident note, troubleshooting plan, or impact assessment.
- It does not say how many SD users are affected.
- It does not confirm whether the issue is team-specific or part of a wider Citrix problem.
- It does not include timing, location, connection type, error details, or business urgency.
- It leaves key terms undefined, such as whether "slow" means login delay, session lag, app launch delay, or general poor responsiveness.

## Better prompt example
Create a structured triage summary for a Citrix performance issue affecting the SD team. Include a one-line summary, impact analysis, known facts, likely causes, missing information to gather, and the first diagnostic step. Assume multiple SD users are affected, but broader business scope is not yet confirmed.

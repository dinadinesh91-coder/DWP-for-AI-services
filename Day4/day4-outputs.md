## Output 2: Intune Explanation
Microsoft Intune is a cloud tool that lets us manage company and personal devices used for work, like Windows 11 laptops, phones, and tablets. It controls settings such as security rules, app installs, update policies, and compliance checks.

A device is enrolled by signing in with a work account and joining through Company Portal or automatic enrollment from Entra ID/Azure AD.

In a Win11 migration, the DWP team uses Intune to:
1. Push required apps (for example Outlook, Teams, VPN client) to upgraded devices.
2. Apply baseline security and configuration policies (for example BitLocker, Defender, and device compliance) so migrated devices stay secure and can access company resources.

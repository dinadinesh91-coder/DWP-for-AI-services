# Disk Health Reporter (PowerShell 5.1)

This document explains how to use the disk health reporter script for DWP engineers.

Script path:

- `Day3\disk-health-reporter.ps1`

## What the script does

- Reports logical disk capacity and free space.
- Reports physical disk health and operational status.
- Reports optimization status by reading Scheduled Defrag task state, defrag service state, and recent optimization-related events.
- Never runs defragmentation or optimization commands.
- Writes a timestamped JSON report and a timestamped log file for each run.

## Read-only safety guarantee

The endpoint health collection is strictly read-only.

- The script does **not** call `Optimize-Volume`, `defrag /O`, or any command that changes disk layout.
- Optional cleanup logic (if enabled) only touches this script's own report artifacts under `Day3\Logs\DiskHealthReports`.

## Parameters

### Report mode

- `-DriveLetters <string[]>`
  Optional list of drive letters to report. Example: `-DriveLetters C,D`.

- `-OlderThanDays <int>`
  Age filter used by report-artifact cleanup. Default: `0`.

- `-DryRun`
  Used with `-CleanupOldReports`. Prints files that would be deleted (quarantined), with no file changes.

- `-CleanupOldReports`
  Enables cleanup of old report artifacts generated by this script.

- `-ReportRoot <string>`
  Folder where JSON reports are written. Default: `Day3\Logs\DiskHealthReports`.

- `-QuarantineRoot <string>`
  Folder used for quarantined report artifacts and rollback manifests. Default: `Day3\Logs\DiskHealthReports-Quarantine`.

- `-LogRoot <string>`
  Folder for timestamped execution logs. Default: `Day3\Logs`.

### Rollback mode

- `-Rollback`
  Restores report artifacts from the latest cleanup manifest by default.

- `-OperationId <string>`
  Restores artifacts for a specific cleanup run.

- `-RollbackManifestPath <string>`
  Restores artifacts from a specific manifest file.

## Requirement mapping

- Dry run list of files to delete:
  Supported via `-DryRun -CleanupOldReports`.

- Older-than-days filter (default 0):
  Supported via `-OlderThanDays`.

- Skip locked files and continue:
  Locked report artifacts are skipped and logged.

- Try/catch per file:
  Implemented in per-file cleanup and rollback loops.

- Timestamped logging:
  Every run creates `disk-health-reporter-<timestamp>.log`.

- End summary:
  Script prints and logs execution summary.

- Comments per section:
  Script contains comments for every major section.

- Rollback:
  Cleanup moves files to quarantine and writes manifest; rollback restores them.

- Idempotent behavior:
  Re-running cleanup skips moved files; rollback marks restored entries and avoids overwrite.

## Examples

Generate disk health report only (default, read-only):

```powershell
.\Day3\disk-health-reporter.ps1
```

Report only selected drives:

```powershell
.\Day3\disk-health-reporter.ps1 -DriveLetters C,D
```

Dry run cleanup of old report artifacts (no file changes):

```powershell
.\Day3\disk-health-reporter.ps1 -CleanupOldReports -OlderThanDays 7 -DryRun
```

Cleanup old report artifacts (quarantine with rollback support):

```powershell
.\Day3\disk-health-reporter.ps1 -CleanupOldReports -OlderThanDays 7
```

Rollback the latest cleanup run:

```powershell
.\Day3\disk-health-reporter.ps1 -Rollback
```

Rollback a specific cleanup run:

```powershell
.\Day3\disk-health-reporter.ps1 -Rollback -OperationId 20260806-110015-123-4321
```

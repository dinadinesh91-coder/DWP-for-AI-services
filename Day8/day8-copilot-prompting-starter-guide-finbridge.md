# FinBridge Microsoft 365 Copilot Prompting Starter Guide

Date: 2026-08-12  
Audience: Non-technical office staff

This guide is designed to help you get useful results fast, using real prompt examples you can copy and adapt.

## Start Here: A simple formula for a good prompt

Use this easy pattern every time:

Task + Source + Format + Style

In plain English:
- Task: What you want Copilot to do.
- Source: Which email, document, meeting, or spreadsheet to use.
- Format: How you want the answer returned (bullets, table, draft email, summary).
- Style: Any simple rules (friendly tone, short answer, for manager, by today).

Quick reusable template:

"Please [task] using [source]. Return it as [format]. Keep it [style]."

Example template in action:

"Please summarise this thread using the last 10 emails. Return it as 5 bullets with actions, owner names, and due dates. Keep it short and suitable for my manager update."

## Outlook prompt examples (ready to use)

### 1) Summarise a long email thread
"Summarise this email thread from the last 7 days. Return:
1) key decisions,
2) open questions,
3) actions with owner names and due dates.
Keep it under 150 words."

### 2) Draft a professional response with options
"Draft a reply to this client email confirming we received the request. Include two timeline options: delivery by Friday or next Tuesday. Keep tone polite and confident. End with a clear question asking which option they prefer."

### 3) Build a daily priority list from inbox
"Review my unread emails from today and create a priority list in this format:
- Urgent (respond in 2 hours)
- Important (today)
- Can wait (this week)
For each item, include one-sentence reason and suggested next action."

## Word prompt examples (ready to use)

### 1) Turn rough notes into a clean briefing
"Using this draft, create a one-page briefing for Finance leadership. Structure it as:
- Situation
- Impact
- Recommendation
- Next steps
Keep language plain and remove repetition."

### 2) Rewrite for a different audience
"Rewrite this document for non-technical office staff. Keep all decisions and deadlines, but simplify jargon and reduce paragraph length. Add a short FAQ section with 5 common questions."

### 3) Improve clarity and consistency
"Edit this policy draft for clarity and consistency. Return:
1) revised version,
2) list of major changes made,
3) any sentences that may be ambiguous.
Do not change the policy meaning."

## Excel prompt examples (ready to use)

### 1) Explain trends from a table
"Analyse the table in this sheet and identify:
- top 3 cost increases compared with last month,
- any unusual spikes,
- one likely business reason for each spike.
Return as a short table with columns: Item, Observation, Possible Reason."

### 2) Build useful formulas with explanation
"Create formulas for these columns:
- Variance (%): Actual vs Budget
- Status: Over Budget, On Track, Under Budget
- Risk Flag: High if variance is above 10%
Then explain each formula step by step in plain English so I can reuse it. If there is a simpler option, show that too."

### 3) Prepare a meeting-ready summary
"From this workbook, produce a 6-bullet executive summary for tomorrow's finance meeting:
- 2 wins,
- 2 risks,
- 2 actions needed.
Keep each bullet under 18 words and include numbers where possible."

## Prompt upgrade tips (quick wins)

If a response is too generic, add one or more of these:
- Be more specific about the source: "Use only the Q3 board pack and today's email thread."
- Ask for a clear shape: "Return as a table with Owner, Action, Due Date."
- Ask it to stick to facts in your files: "Use only points found in the source content."
- Set a size limit: "Keep this to 120 words max."

## Data safety habit (Day 1 reminder)

Important FinBridge habit from Day 1:
- Keep business data inside approved FinBridge tools.
- Do not paste confidential client, payroll, board, or M&A information into external AI tools.

This is a safety habit, not a reason to avoid Copilot.
You should still use Microsoft 365 Copilot for day-to-day work inside your FinBridge account.

Safe practice:
- Use Microsoft 365 Copilot within your company account for work content.
- If unsure whether data is sensitive, treat it as sensitive and ask your manager or IT/security team before sharing.

## A simple 30-second pre-send check

Before pressing Enter on any prompt, ask:
1. Am I in the correct FinBridge work account?
2. Did I give Copilot enough context to be useful?
3. Did I avoid sharing confidential data outside approved tools?

If all three are yes, send it.

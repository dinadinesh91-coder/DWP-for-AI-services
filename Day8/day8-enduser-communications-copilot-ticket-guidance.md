# End-User Communications - Copilot Ticket Guidance

Date: 2026-08-12  
Audience: End users who raised Copilot-related tickets

Purpose:
- Explain each issue in plain English.
- Give practical next steps the user can take immediately.
- Set clear expectations on what IT will check next.

## Ticket 1 - Finance lead cannot summarise Q3 board pack in SharePoint

Plain-English explanation:
You can open the board pack, but Copilot may still be blocked from using that file if extra protections are applied (for example, strict sensitivity settings or restricted access rules).

Next steps for you:
1. Confirm the exact file name and location you want Copilot to use.
2. Check whether the file is marked with a high-security label.
3. Share the file link with IT so we can validate the access and protection settings.

What IT will do:
1. Verify file permissions and security label settings.
2. Confirm whether Copilot is allowed to use that protected content.
3. Update access/protection only if policy allows it.

## Ticket 2 - New hire says Copilot in Outlook knows nothing about recent emails

Plain-English explanation:
Because your account is new, Copilot may need time to build context from your mailbox. This usually catches up after account setup and indexing complete.

Next steps for you:
1. Confirm you are signed into the correct work account in Outlook.
2. Wait a short period and try again.
3. If still the same, send IT a screenshot of Outlook account details and Copilot response.

What IT will do:
1. Confirm your Copilot license is active.
2. Confirm your Outlook client is on a supported version.
3. Check mailbox indexing/status in Microsoft 365.

## Ticket 3 - HR manager cannot pull from sensitive salary spreadsheet

Plain-English explanation:
Copilot is enforcing access rules. If Copilot says it does not have access, it usually means your account is not allowed to use that spreadsheet in this context, or the file has strict protection.

Next steps for you:
1. Verify you can open the spreadsheet directly with your account.
2. Send IT the file link and where it is stored.
3. Confirm whether this is expected HR-only content or broader manager content.

What IT will do:
1. Validate your effective permissions on the file and library.
2. Check for extra sensitivity restrictions.
3. Confirm whether access should be expanded or remain restricted per policy.

## Ticket 4 - Sales rep cannot find contract shared by guest link from another org

Plain-English explanation:
Content shared through external guest links may not appear to Copilot the same way as internal company content.

Next steps for you:
1. Confirm the contract owner and source organization.
2. Share the guest link and where you received it.
3. Ask the owner for an internal approved sharing path if needed for Copilot use.

What IT will do:
1. Confirm this is a cross-organization guest-sharing scenario.
2. Check current tenant sharing policy behavior for Copilot access.
3. Recommend compliant alternatives for contract access.

## Ticket 5 - Copilot stopped for whole Finance team this morning

Plain-English explanation:
If everyone is affected at once, this is usually a setup or entitlement issue (for example, license or policy change), not a user mistake.

Next steps for you:
1. Do not reinstall apps yet.
2. Share one example error message or screenshot from a Finance user.
3. Confirm when the issue started and who is affected.

What IT will do:
1. Check Finance Copilot license assignments and service plans.
2. Check recent policy/configuration changes.
3. Validate service health and provide a status update.

## Ticket 6 - Manager saw Copilot summarise a file they forgot they could access

Plain-English explanation:
Copilot can use content you already have permission to access, even if you forgot that permission existed.

Next steps for you:
1. Share the file link and folder path with IT.
2. Tell us whether you still need access to that location.
3. Report any content you believe should be restricted.

What IT will do:
1. Review your effective permissions on that location.
2. Remove unnecessary access if no longer required.
3. Raise a broader permission cleanup if similar cases are found.

## Ticket 7 - Analyst gets generic answers, no internal SharePoint grounding

Plain-English explanation:
Generic responses usually mean Copilot is not fully connected to your expected work context (account, license, supported app version, or access scope).

Next steps for you:
1. Confirm you are in the correct company tenant/account.
2. Use a specific prompt with a known internal file name or site.
3. Share one prompt example and response with IT.

What IT will do:
1. Verify your license and app/client readiness.
2. Validate SharePoint access scope for your account.
3. Check whether indexing is still catching up.

## Ticket 8 - Executive assistant cannot access shared mailbox calendar in Copilot

Plain-English explanation:
Delegate/shared mailbox scenarios do not always behave the same way for Copilot as direct mailbox ownership.

Next steps for you:
1. Confirm your current delegate permissions for the director mailbox.
2. Share which exact calendar action failed in Copilot.
3. Provide a screenshot of the Copilot message.

What IT will do:
1. Verify delegate permission levels and access path.
2. Confirm supported behavior for shared mailbox calendar use in your client.
3. Provide workaround or permission adjustment if available.

## General user guidance for faster resolution

1. Include exact app name (Outlook, Teams, Word, etc.), time of issue, and screenshot.
2. Include file/site/mailbox link when relevant.
3. Tell us whether the issue affects only you or multiple people.
4. Avoid sharing sensitive data in tickets; share links and metadata instead.
